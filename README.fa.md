## 💡 پیش از استفاده بدانید

- **وردپرس مستقل:** متن، غذا، قیمت و دسته‌ها را از فایل منو وارد می‌کند؛ قالب و بوم آزاد منتقل نمی‌شوند و تغییرات بعدی نیاز به ورود دوباره دارند. تصاویر به میزبان اولیه وابسته می‌مانند، مگر آن‌ها را منتقل کنید.
- **وردپرس زنده:** طراحی کامل منوی برنامه را نمایش می‌دهد؛ سرور برنامه باید روشن و دامنهٔ وردپرس برای نمایش در قاب مجاز باشد. [راهنمای وردپرس](docs/WORDPRESS.md)
- **پشتیبان‌گیری:** خروجی محتوای منو، پشتیبان کامل نیست. از پایگاه‌داده، تصاویر و کلید نشست با هم نسخهٔ پشتیبان بگیرید.
- **محدودهٔ برنامه:** ثبت سفارش، پرداخت اینترنتی، رزرو و مدیریت ارسال پیاده‌سازی نشده‌اند. ورود فایل صفحه‌گسترده و بازیابی رمز از طریق ایمیل هم وجود ندارد.
- **برچسب‌های غذایی:** این اطلاعات را مسئول رستوران وارد می‌کند؛ به‌تنهایی تضمین مناسبت غذا برای حساسیت غذایی نیستند.

## اجرای سریع

### ویندوز

از [صفحهٔ انتشارها](https://github.com/unknown-killer/MenuCraft/releases) فایل ZIP ویندوز متناسب با پردازنده را بگیرید؛ بیشتر رایانه‌ها **amd64** هستند. فایل را در پوشه‌ای قابل‌نوشتن استخراج کنید و **run.bat** را اجرا کنید.

[نشانی محلی برنامه](http://127.0.0.1:8080) را باز کنید، ثبت‌نام کنید و منوی خود را بسازید. هنگام استفاده، پنجرهٔ برنامه باید باز بماند.

### اجرا از سورس

پیش‌نیاز: **Go نسخهٔ 1.26.9 یا جدیدتر**. برای خود برنامهٔ Go به Node.js، PHP یا کامپایلر C نیاز نیست.

</div>
<div dir="ltr" align="left">

```sh
go mod download
go run .
```

</div>
<div dir="rtl" align="right">

اجرای مستقیم Go به‌صورت پیش‌فرض روی `:8080` است. برای محدودکردن دسترسی به رایانهٔ خود، متغیر `MENU_ADDR` را برابر `127.0.0.1:8080` بگذارید.

نسخهٔ اجرایی، قالب‌ها، CSS، جاوااسکریپت و قلم وزیرمتن را درون خودش دارد. پایگاه‌داده، کلید نشست و پوشهٔ تصاویر در اولین اجرا ساخته می‌شوند.

برای مشاهدهٔ نمونه روی یک پایگاه‌دادهٔ آزمایشی:

</div>
<div dir="ltr" align="left">

```sh
go run ./cmd/seed
go run .
```

</div>
<div dir="rtl" align="right">

منوی نمونه در `/m/demo` و حساب آن با نام `demo` و رمز `Demo1234` است. اجرای مجدد seed، منوی همان حساب را جایگزین می‌کند؛ آن را روی اطلاعات واقعی اجرا نکنید. ساخت حساب نمونه در کانتینر تولید به‌صورت پیش‌فرض خاموش است.

## ساخت اولین منو

1. ثبت‌نام و نوع مجموعه را انتخاب کنید.
2. دسته و غذا اضافه کنید یا یکی از منوهای آماده را اعمال کنید.
3. قیمت، موجودی، اطلاعات تماس و ساعات کاری را تنظیم کنید.
4. قالب دلخواه را انتخاب و هر دو زبان را پیش‌نمایش کنید.
5. در تنظیمات، منو را منتشر کنید و لینک `/m/your-slug` یا QR مسیر `/m/your-slug/qr` را به اشتراک بگذارید.

منوی منتشرنشده فقط برای مالک واردشده قابل مشاهده است. علاقه‌مندی‌ها در مرورگر مشتری ذخیره می‌شوند و حساب کاربری لازم ندارند. برچسب‌های رژیم غذایی را مسئول رستوران تعیین می‌کند.

## تنظیمات

متغیرها را در محیط اجرا، سرویس یا کانتینر تنظیم کنید. برنامهٔ اجرایی فایل `.env` را خودکار نمی‌خواند.

| متغیر | پیش‌فرض | کاربرد |
|---|---|---|
| `MENU_ADDR` | `:8080` | نشانی و پورت HTTP |
| `MENU_DB` | `data/menu.db` | فایل SQLite |
| `MENU_UPLOADS` | `uploads` | مسیر تصاویر |
| `MENU_ENV` | `development` | برای HTTPS از `production` استفاده کنید؛ کوکی امن و فایل‌های داخلی فعال می‌شوند |
| `MENU_PUBLIC_URL` | خالی | دامنهٔ اصلی مثل `https://menu.example.com` برای QR و خروجی |
| `MENU_EMBED_ORIGINS` | خالی | دامنه‌های مجاز برای نمایش منوی عمومی در iframe، جداشده با کاما |
| `MENU_DISABLE_REGISTRATION` | `false` | پس از ساخت حساب‌ها، با `true` ثبت‌نام جدید را ببندید |
| `MENU_SECRET` | خودکار | کلید اختیاری امضای نشست، حداقل ۳۲ بایت |
| `MENU_LOCALE` | `fa` | زبان پیش‌فرض؛ `fa` یا `en` |
| `MENU_MAX_UPLOAD` | `8388608` | حداکثر حجم تصویر برحسب بایت |
| `MENU_SESSION_TTL` | `720h` | اعتبار نشست |

کلید خودکار در فایل `.secret` کنار پایگاه‌داده نگهداری می‌شود؛ آن را همراه داده‌ها حفظ کنید. مسیر `/healthz` زنده‌بودن فرایند و `/readyz` اتصال پایگاه‌داده را بررسی می‌کند.

## نسخهٔ وردپرس

ZIP افزونه را از انتشارها بگیرید و در **افزونه‌ها ← افزودن ← بارگذاری افزونه** نصب و فعال کنید. سپس به **تنظیمات ← MenuCraft** بروید.

- **حالت مستقل:** در پنل Go از بخش «انتقال منو» خروجی JSON بگیرید، در وردپرس وارد کنید و شورت‌کد `[menucraft_menu lang="fa"]` یا `[menucraft_menu lang="en"]` را داخل برگه بگذارید.
- **حالت زنده:** نشانی منوی منتشرشدهٔ Go را تنظیم کنید و دامنهٔ وردپرس را به `MENU_EMBED_ORIGINS` سرور Go اضافه کنید.

حالت مستقل محتوای منو، قیمت‌ها، جست‌وجو و دسته‌بندی را با ظاهر واکنش‌گرا نمایش می‌دهد. طراحی قالب و بوم Go منتقل نمی‌شود و تغییرات بعدی نیاز به ورود دوبارهٔ JSON دارند. تصاویر تا زمانی که به وردپرس منتقل نشده‌اند به میزبان اولیه وابسته‌اند. در حالت زنده، سرور Go باید روشن بماند. [راهنمای کامل وردپرس](docs/WORDPRESS.md).

دستور آخر نسخه‌های **ویندوز و لینوکس برای amd64 و arm64**، اسکریپت اجرا، مستندات، ZIP وردپرس و فایل SHA-256 را در `dist` می‌سازد. Go و Git برای ساخت لازم‌اند. بررسی امضای ماژول‌های Go را غیرفعال نکنید.

تست‌ها احراز هویت، CSRF، جداسازی دادهٔ حساب‌ها، حریم منوی پیش‌نویس، محدودیت درخواست، عملیات تراکنشی، قالب‌ها، تنظیمات و موتور ظاهر را پوشش می‌دهند. [گزارش بررسی](docs/VERIFICATION.md)، [معماری و اصلاحات](docs/ARCHITECTURE.md)، [تغییرات نسخه](CHANGELOG.md).

## پشتیبان‌گیری و محدودیت‌ها

JSON فقط برای **انتقال محتوای منو** است؛ حساب‌ها، رمزها، کلید نشست، خود فایل تصاویر، قالب‌ها، بوم و تنظیمات ساعات کاری را منتقل نمی‌کند. برای بازیابی کامل باید پایگاه‌داده، تصاویر و کلید امضا با هم پشتیبان گرفته شوند؛ مراحل در [راهنمای استقرار](docs/DEPLOYMENT.md) آمده است.

استقرار فعلی برای یک سرور با فضای ذخیره‌سازی ماندگار طراحی شده است. اجرای چند سرور روی یک فایل مشترک SQLite پشتیبانی نمی‌شود. بازیابی رمز از طریق ایمیل وجود ندارد؛ مالک پس از ورود می‌تواند رمز را تغییر دهد.
