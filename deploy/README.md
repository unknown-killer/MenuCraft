# Deployment / استقرار

See [the deployment guide](../docs/DEPLOYMENT.md) for Linux/systemd, Windows, Docker Compose, HTTPS, persistence and backup procedures.

راهنمای کامل اجرا، HTTPS، متغیرهای محیطی و پشتیبان‌گیری در [راهنمای استقرار](../docs/DEPLOYMENT.md) است.

The Compose configuration binds only to loopback and does not create a demo account by default. Set the canonical public URL and put an HTTPS proxy in front before using production login.
